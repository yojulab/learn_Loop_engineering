# Working Guidelines — 컨텍스트 오염 방지 4원칙

## 컨텍스트 오염(Context Pollution) 4대 유형
1. **도구 출력 범람(Tool Output Bloat)**: 대용량 로그·전체 파일을 필터 없이 출력해 핵심 지침을 밀어내는 현상
2. **추론 찌꺼기 누적(Stale Reasoning Drift)**: 실패한 시도와 폐기된 가설이 대화창에 남아 다음 판단을 왜곡하는 현상
3. **무관 파일 과적재(Irrelevant File Loading)**: 수정 대상과 무관한 모듈까지 미리 읽어 Lost-in-the-Middle 현상을 유발하는 현상
4. **상충 규칙 혼재(Conflicting Rules)**: 전역 지침과 경로별 지침이 충돌해 우선순위가 흐려지는 현상

## 실전 방어 가이드라인 4원칙
1. **범위 우선 탐색**: 전체 파일을 읽기 전 검색(`rg`)과 필요한 함수 구간만 발췌해 읽는다.
2. **상태 외재화**: 완료된 작업과 결정 근거는 대화창이 아니라 `TASKS.md`와 `JOURNAL.md`에 남긴다.
3. **임계치 관리**: 컨텍스트 점유율이 75%에 도달하면 `/compact`로 요약하고, 작업 주제가 바뀌면 `/clear`로 초기화한다.
4. **지침 계층화**: 공통 규칙은 1층위(`CLAUDE.md`)에, 경로 특화 규칙은 2층위(`.claude/rules/`)에 분리한다.
